◆ parseMIDI()

void InputronicParser::parseMIDI ( const String & msgIn)
private

Parse MIDI message payload.

The firmware accumulates multiple MIDI events per USB transfer into a single packet: TS;MIDI;b1;b2;b3|b1;b2;b3|...;TE Only the first event is stored in the struct; the struct can be extended in a future revision to hold all events.
